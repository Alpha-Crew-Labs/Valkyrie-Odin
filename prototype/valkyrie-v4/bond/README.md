# 채권 위기 진단 & 액션 플랜

한국 국고채 시장의 위험 신호를 매일 진단하고, 그 결과를 매매 권고(듀레이션·만기·선물 헤지)로 바꿔 주는 파이프라인과 설명용 앱입니다.

## 실행

`대시보드` 폴더에서 `run_bond_app.bat`을 더블클릭하거나:

```powershell
powershell -ExecutionPolicy Bypass -File .\run_bond_app.ps1            # 앱 실행 (처음이면 패키지 자동 설치)
powershell -ExecutionPolicy Bypass -File .\run_bond_app.ps1 -Refresh   # 데이터 갱신 후 실행
```

브라우저에서 http://localhost:8511 을 엽니다. 앱의 사이드바에서도 **🔄 최신 데이터로 새로고침**으로 갱신할 수 있습니다.

필요한 것: Python 3.11 이상, 한국은행 ECOS API 키(`ECOS_API_KEY`를 `대시보드/.env` 또는 `채권/.env`에).

## 파이프라인 (`data/30_BOND`에 결과 저장)

| 단계 | 스크립트 | 하는 일 |
|---|---|---|
| 1 | `collect_korea_bonds.py` | ECOS에서 국고채 9개 만기·회사채·CD/CP 금리 수집, 스프레드 계산 |
| 2 | `kim_filter_korea_bond_real.py` | Kim Filter(3상태 × 3요인)로 시장 상태 확률 추정 |
| 3 | `crisis_dashboard.py` | 금리 위기 점수(4개 지표) + 신용 스트레스(크레딧 스프레드), 위기 구간 탐지, 종합 판정 |
| 4 | `action_plan.py` | 목표 듀레이션·커브 포지션·현물/선물 주문·크레딧 비중·백테스트 (`--aum 1000`으로 운용규모 지정) |
| 앱 | `explainer_app.py` | 위 결과를 설명하는 Streamlit 앱 |

## 규칙 요약

- **목표 듀레이션** = 벤치마크(국고 3Y/10Y 50:50) × (평소 변동성 ÷ 최근 20일 변동성), 0.3~1.2배. 차이가 0.5년 이상일 때만 매매.
- 위기 신호는 금리 **방향**은 예측하지 못하고(상관 ±0.06) **변동성**은 잘 예측해서(0.62~0.72), 방향 베팅 대신 위험 크기를 맞추는 규칙을 택했습니다.
- **신용 스트레스**(모형 C) = AA- 스프레드와 CP−CD 스프레드의 수준(누적 z)·20일 확대폭 가중합. 종합 판정은 금리와 신용 중 더 나쁜 쪽. 금리 점수만으로는 2020년 코로나 신용경색(금리 점수 0.27)을 놓쳤지만 신용 스트레스는 1.0이었습니다.
- **크레딧 비중** = 회사채 AA- 3년(국고 3년과 교체, 듀레이션 중립). 스프레드가 20일간 +5bp 넘게 확대 중이면 10%, 아니면 20% + 10%p × 스프레드 누적 z(−1~+2) → 10~40%. 고정 20% 대비 위기 해(2020·2022·2023)에 모두 우위, 최대 손실폭 축소. 부도 손실은 미반영.
- 백테스트(2017-03~2026-09 데이터 기준, 갱신 시 앱에서 최신값 확인): 연수익 0.95% vs 0.99%로 거의 같고, 변동성은 −31%, 최대 손실폭은 −14.3% → −10.6%. 위기 직후 반등장에서는 뒤처집니다.

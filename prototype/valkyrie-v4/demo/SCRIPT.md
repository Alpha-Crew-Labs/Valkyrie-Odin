## 다시 녹화하기

화면이나 엔진이 바뀌면 영상도 새로 뽑아야 합니다. 자막과 음성 속 숫자는 녹화 직전에 엔진 API에서 다시 읽어 옵니다.

```powershell
# 대시보드 서버가 켜진 상태에서 (..\run.ps1)
.\make_demo.ps1            # 녹화 → 본편 + 자막본 + 음성본 + 캡처 (약 15분)
.\make_demo.ps1 -NoAI      # 화면 배치만 점검 (AI 질문 · 발간 없음, data\state에 아무것도 쓰지 않음)
.\make_demo.ps1 -Compose   # 녹화 없이 다시 합성 (자막 모양 수정 등)
```

- 음성 바꾸기: `python record_demo.py --voice ko-KR-InJoonNeural --rate +10%` (남성: InJoon · HyunsuMultilingual)
- 전체 녹화 1회마다 AI 질문 1건(약 $0.05)이 나가고, `data/state/publish.json`에 게시글 1건이 쌓입니다.
- 내레이션 문장은 `record_demo.py`의 `script()`, 장면 순서는 `demo()`에 있습니다.
- 음성은 Microsoft 온라인 TTS(edge-tts)로 만듭니다. 이때 내레이션 문장만 전송하고, 같은 문장은 `_work/tts`에 캐시합니다.
- 화면 구조가 바뀌면 녹화 로그에 `! not found` / `! timeout`이 찍힙니다. 그 부분만 고치면 됩니다.
